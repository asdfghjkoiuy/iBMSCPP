## `.wos` 格式

帮助只写了文件名规则：把读入声音路径的 `.wav` 换成 `.wos`。`[T][Y]` 是一对「简易读写」，没有写谁读谁写，也没有写文件正文。

归档里没有 `.wos` 样例。**正文格式从帮助和归档看不出来。**

## 几何

| 项目 | 状态 |
| --- | --- |
| II 客户区宽高 | 待运行时从 Windows 原版量 |
| III 客户区宽高 | 待运行时从 Windows 原版量 |
| 控件坐标、字号、颜色、波形区尺寸 | 待运行时从 Windows 原版量 |
| 窗口装饰 | 由系统负责；不属于客户区基线 |

切片、BMSE 剪贴板和预览已挂进共用 `Audio Slicer` 窗，不再当独立主程序。woslicer 模式按裁断线切 PCM16，文件名 `原名_001.wav` 起。帮助没写切点公式，缺起点时补 `0`，这是工作规则。剪贴板用 `BMSE ClipBoard Object Data Format`，B 列 ident `101`。秒换 vpos：`seconds * BPM / 60 * 48`。连号默认从 `1` 起；FF 打开则值都是 `555`。`[P]` / Enter 播当前段，`[O]` 播前一段；起止秒帮助没写，按同一套切点接到文件末尾。`[Z]` 切换当前秒的裁断线，`[C]` 清空，`[M]` 按原名切片。这些也是工作规则。波形已挂进共用窗。取样和尺寸是工作规则：窗 `800 × 460`，波形带 `780 × 80`。末端全 0 帧已按工作规则去掉。仍没有 `.wos`，没有边缘检测，也还没量原版客户区。未截图，不能拿来当原版客户区验收。
