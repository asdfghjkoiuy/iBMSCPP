# μBMSC / iBMSC legacy themes

Implemented in `macos/Sources/IBMSNative/ChartTheme.swift` is the bounded, appearance-only compatibility model for original iBMSC theme XML. It loads and exports the `<Columns>` and `<VisualSettings>` parts of an `<iBMSC>` document. It deliberately has no chart data, undo/history, player path, playback, form, or other settings fields, so a theme import cannot change them.

The bundled source resources are copied verbatim from `iBMSC/misc/Data` (UTF-16LE): `BMSE`, `BMSEmdk`, `BMSEmdkp`, `Forme`, `IIDX`, `MyO2_4K`, `O2Mania`, and `Pomu`. The source attribution is the iBMSC repository's `misc/Data/*.Theme.xml`; the files were preserved byte-for-byte. Menus can enumerate `Resources/Themes/*.Theme.xml`; for named originals, use `try ChartTheme.bundledTheme(.iidx, bundle:)` or `.o2Mania` (the explicit `builtInIIDX` and `builtInO2Mania` helpers are also available). A missing or malformed resource is surfaced to the controller and is never silently presented as a default theme.

The codec accepts UTF-8 and UTF-16 input up to 1 MiB, rejects DTD/entity declarations and malformed XML, and recognizes only exact `iBMSC/Columns/Column` and `iBMSC/VisualSettings/*` paths for mutation. It retains the original partial-load rule: every absent attribute or visual leaf inherits the supplied base theme. `Display` is therefore preserved when absent; a present `Width="0"` still makes `ThemeColumn.effectiveVisible` false. Column width is constrained to 0…10,000, pixel dimensions and shifts to safe drawing ranges, font sizes to 0.1…512 points, and opacity to 0…1; invalid values produce diagnostics and retain the base state. Out-of-range indexes and unsupported non-visual elements are reported as diagnostics. Unsupported `VisualSettings` leaves are retained as attribute-only records and written back during export.

The model stores signed .NET `Color.ToArgb()` values as strongly typed `ThemeColor` (`AARRGGBB`) and carries normal-note, LN, text, long-text, and background colours; widths, titles, visibility; all legacy grid/selection/border colours; fonts; note height; label shifts; and hidden-note opacity. XML font `Size` is `Font.SizeInPoints`; renderer code should use `ThemeFont.logicalPixelSize` (`points × 4/3`) for the source's 96-DPI logical-pixel scale.

Lane header keys are legacy `EditorColumns` indexes. In the default IIDX order they map to BMS channels: index 5 → 16 (scratch), 6 → 11, 7 → 12, 8 → 13, 9 → 14, 10 → 15, 11 → 18, 12 → 19; indexes 14…21 → 21, 22, 23, 24, 25, 28, 29, 26 (scratch). This model only affects appearance and does not reinterpret chart channels.

For source fidelity, note endpoint brightness is component-wise, not HSB/HSL: bright is `roundEven(0.5 × RGB + 127.5)` and dark is `roundEven(0.75 × RGB)`. The legacy code calls `AdjustBrightness` with `A / 255`, so the derived endpoint has `roundEven(A² / 255)` alpha before any hidden-note opacity; hidden notes then multiply that alpha by `kOpacity` with the same .NET/VB banker rounding. `kOpacity` is passed only for hidden notes in `DrawNote`; it must not be applied globally to LN bodies.

This covers the original theme XML appearance contract used by the current native shell. It does not claim compatibility with unimplemented μBMSC 2.x settings, UI behavior, plugins, or other runtime configuration.

`EditorThemeController` is the native AppKit owner for this appearance state. The Theme menu matches `cmnTheme`: `(Default)`, `Save Theme`, `Refresh`, `Load Theme File from iBMSC 2.x`, a separator, then `*.Theme.xml` filenames from Refresh. Refresh merges bundled `Resources/Themes` with the user Data directory (`~/Library/Application Support/IBMSNative/Data`); a user file of the same name wins. `(Default)` loads bundled O2Mania. `Save Theme` writes UTF-16 XML through `ChartThemeCodec.exportTheme` into the injected Data folder. `Load Theme File from iBMSC 2.x` parses `.th` text with `LegacyThemeCompatibility` against the current theme. On startup it restores only valid saved XML, otherwise stages the bundled IIDX resource; `Form_Load` only Refresh, never `(Default)`. Resource errors are reported and never mislabeled as IIDX. Its required `apply(ChartTheme)` callback is appearance-only, so it cannot make a BMS document dirty. The controller accepts parent-window and begin/end-sheet callbacks; every open/save panel and alert is coordinated through them, allowing the main controller to block edits while a sheet is active.

The codec continues to preserve source `Display` faithfully. In the current native layout integration, the active side selector overrides a source `Display=false` for its mapped lanes, while `Width=0` remains an unconditional effective hide. This is a renderer/layout policy, not an XML codec rewrite.
