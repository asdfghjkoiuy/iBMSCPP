# 内置预览器控制

在 iBMSC 编辑器中，F5 从头播放、F6 从鼠标指针所在拍播放、F7 停止。菜单和工具栏走同一个内置预览窗。macOS 若把功能键用于系统功能，F1/F2/F5/F6/F7 可能需要同时按 Fn；紧凑键盘上的 Page Up/Down、Home/End 可按系统的 Fn 组合键。

数字键看键盘焦点。预览窗口的内容区获得焦点时，数字键只控制预览。焦点回到编辑器谱面后，数字键仍按原来的规则移动已选音符。两边不共用一次按键。编辑器保持 iBMSC 原有列编号：数字 1 对应搓盘列，数字 2 对应视觉第二列（BMS 通道 11），数字 3 对应下一键列（通道 12）。

速度是固定档，一次物理按下只动一档。系统连发和播放中的按键轮询都不会连跳。松开后再按，才进入下一档。已经在端点就停住。不能靠按住越来越快。

## 下落速度 HiSpeed

19 档，含两端，每档 0.25：

0.50、0.75、1.00、1.25、1.50、1.75、2.00、2.25、2.50、2.75、3.00、3.25、3.50、3.75、4.00、4.25、4.50、4.75、5.00

1 倍是 48 像素每拍。上表对应 24、36、48、…、240 像素。播放区仍把任意像素夹在 16…240，这些档全部落在里面，所以显示的倍率就是画面用的倍率。0.25 倍不再作为一档，因为它会变成 12 像素，然后被抬到 16 像素。

只按 1 降低一档，只按 2 提高一档。1 和 2 同时按住时朝 1.00 移一档；已经是 1.00 就不动。

## 播放倍速

16 档，含两端，每档 0.25：

0.25x、0.50x、0.75x、1.00x、1.25x、1.50x、1.75x、2.00x、2.25x、2.50x、2.75x、3.00x、3.25x、3.50x、3.75x、4.00x

内部仍按百分数交给原来的 `setPlaybackRate`，100 表示 1.00x。实际能用的档还要小于等于当前运行上限。默认上限是 4.00x。上限若落在两档之间，最高只到不超过它的那一档。上限低于 0.25x 时，速度收成该上限本身，键不再往上加。

只按 3 降低一档，只按 4 提高一档。3 和 4 同时按住时朝 1.00x 移一档。暂停时也可以改，改完仍保持暂停。倍速改变声音和谱面时间，不改变 HiSpeed 的像素。

不在上表里的旧值，下一次按下会沿该键的方向落到相邻档上。比最低档还小或比最高档还大时，这一下先落到该端的档上。

## 在界面上的位置

- 控制条第二行有 HS 和 Rate 的当前值，以及减号、加号。点一下只动一档。Keys 打开快捷键说明。
- 预览内容区菜单有 HiSpeed 和 Rate 子菜单，列出每一档，当前档打勾。Shortcuts 子菜单写着按键、双键、按住不连跳、Fn，以及焦点规则。
- 青色播放信息在默认的 Play 块里有一行 `HS 1.00 RATE 1.00`。不必按 9。按 9 切到不含播放信息的模式后，控制条和菜单仍显示当前值。

## 全部按键

下面按键在预览窗口获得键盘焦点时使用。

| 按键 | 功能 |
| --- | --- |
| 1 / 2 | HiSpeed 降低 / 提高一档。只改变谱面移动速度 |
| 同时按住 1 和 2 | HiSpeed 朝 1.00 移一档 |
| 3 / 4 | 播放倍速降低 / 提高一档。改变声音和谱面时间 |
| 同时按住 3 和 4 | 播放倍速朝 1.00x 移一档 |
| 0 | 暂停 / 继续 |
| ↑ / ↓ | 向前 / 向后定位一小节。按住会重复，间隔从 50ms 起并除以 1.3 |
| Page Up / Page Down | 向前 / 向后定位四小节。按住重复，规则和方向键相同 |
| Home / End | 定位开头 / 最后有内容的小节。按住不重复 |
| 滚轮 | 按小节定位 |
| 空格按住约 0.5 秒 | 从当前编辑内容重新载入谱面 |
| 5 | 循环 BGA 模式：关闭、基础层、叠加层、正常、始终 MISS |
| 6 | 循环判定文字、爆炸、光束的组合开关 |
| 7 | 切换窗口置顶 |
| 8 | 循环 1P/2P 搓盘左右位置 |
| 9 | 循环信息显示：关闭、播放、曲目与选项、全部 |
| F1 | 循环音源模式：BGM、KEY、KEY&BGM、MINE、KEY&BGM&MINE。可能需要 Fn |
| F2 | 切换双侧布局的自动分开选项。可能需要 Fn |

2026-10-21：HiSpeed 与播放倍速以上表为准。定位键的按住重复没有改。表格来自当前键盘映射；不代表每个模式的声音和画面都已完整验收。
