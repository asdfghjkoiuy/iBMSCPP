# 兼容性验收要求

本文定义重写项目的设计和验收要求。它不表示任何功能、性能或截图已经验收通过。
所有实现必须覆盖 iBMSC、µBMSC、bmhelper、BmsONE、woslicer II 和 woslicer III 的全部能力。不得把「最小可用版本」当成完成，也不得把未研究的功能排除在范围外。

产品是一个软件。不要做成四个并列的原版克隆窗。能共用的界面就共用：主编辑器一套显示，底下是 BMS 和 BMSON 两套格式；切片一类工具一套界面，后端按来源分模式。原版独有的对话框仍按各自来源做，挂在同一软件里。「分开建模」只约束数据，不约束窗口。

## 1. 来源、版本和证据

每项能力先登记来源、准确版本、许可证、取得方式和可复现的原始材料。本地 `iBMSC/README.md` 明确说明 µBMSC 是修改版 iBMSC；当前唯一已确认的代码基线是本地 µBMSC 提交 `f5b21d1de50ce28202d1b2e8d2f614fabde18092`，其中包含继承的 iBMSC 代码。历史 iBMSC 发布版本、bmhelper、BmsONE、woslicer II、woslicer III 的准确版本和逐项行为仍待核对。

`docs/development-workflow.md` 已记录 woslicer II、III 的作者归档与初步材料；归档没有源代码这一事实只适用于已检查的归档，不能据此减少功能范围。后续记录必须区分源码、二进制、帮助文件、实际运行观察和截图，不能把推测当作证据。

## 2. 强制兼容目标

行为必须严格复现原始 VB 程序和相应工具的可观察结果，包括菜单、快捷键、鼠标操作、焦点、默认值、错误提示、撤销重做、保存、导入导出和设置生效时机。除行为代码外，所有 `.designer.vb` 也属于审查对象；控件层级、停靠、尺寸、Tab 顺序、默认值、资源和事件连接都要逐项核对。

µBMSC 的应用控制客户区是像素级复现目标。每次视觉验收必须记录参考版本、操作系统、DPI 缩放、显示器、窗口客户区几何、字体及版本、主题、截图步骤和参考截图。`MainWindow.designer.vb` 的已观察基线为 `AutoScaleMode.None`、客户区 `1082 × 730`、`Segoe UI` 9 pt（第 4166—4173 行）。

窗口装饰由平台控制，必须在截图和差异报告中单独标出，不能和客户区混为一谈。字体栅格化与平台装饰都不会自动获得豁免：应用控制客户区仍须达到像素级目标；若某项比较范围、容差或排除项确有必要，必须由用户作出明确记录的决定，写明原因、平台和影响。当前没有实际截图核验记录，因此不得宣称截图已通过；也不在用户未决定前提出仿制 Windows 装饰的方案。

## 5. 格式模型和转换

BMS 与 BMSON 使用独立的领域模型和独立优化路径，但共用同一套编辑器界面。BMS 模型必须表达小节的有理位置、通道、各种长音符表示、随机／条件分支及原始未知字段；这些信息在读取、编辑和保存后必须可追溯。BMSON 模型必须表达其分辨率、声音通道、续播关系和切片语义，不能套用 BMS 的量化假设。打开 `.bms` 走 BMS 模型，打开 `.bmson` 走 BMSON 模型；人看到的是同一条时间线和同一套操作。

跨格式转换要先给出字段映射和可证明的保留条件。无法无损表达时，界面和结果必须明确说明丢失、近似、展开或保留为原始数据的内容，并用双向夹具验证。具体 BMS 与 BMSON 细节、LN 变体和工具私有字段仍待从原始来源核对；在核对完成前，不能假定映射正确。

## 6. 性能、结构和执行要求

「性能优于原程序」只是待测目标，不是既成结论。比较必须定义可比的硬件、谱面、音频、操作序列、运行时、构建配置和重复次数，并记录延迟、帧率、内存、加载时间和保存时间。原程序在 Windows、新程序在 macOS 原生运行或虚拟机运行时，报告必须披露操作系统和虚拟机差异；不得把差异只归因于代码。报告要附原始结果与计算方法，并写明未达标项。

代码按依赖方向分层：界面依赖应用服务，应用服务依赖领域模型，领域模型不依赖界面或平台。音频和绘制实时路径不能等待磁盘、网络、锁竞争或长时间分配；不能用一个「万能类」承载格式、界面、音频和状态。实现和修复只由 `gpt-5.6-luna` 或 `gpt-5.6-terra` 子代理完成；父代理负责契约、独立差异审查、测试和集成批准，规则与 `docs/development-workflow.md` 一致。

## 7. 通过条件

一次验收只对矩阵中有明确来源、版本、测试夹具、结果和审查记录的行作出结论。完整通过要求所有来源的全部能力都有通过证据，所有格式损失都有明示处理，所有客户区截图均在记录条件下完成像素比较，且性能结果达到预先定义的可比任务目标。当前状态：设计和验收要求已写明；功能、格式、截图和性能均待验证。
