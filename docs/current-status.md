## 产品要求（已确认）

用 C++ 核心加 macOS 原生界面，做成**一个软件**。把这些工具的全部可观察能力都还原进去：

- iBMSC / µBMSC
- bmhelper（对话里也叫 ubmshelper）
- BmsONE
- woslicer II / III

不要做成四套独立程序。能力都要在，入口合成一套。

主编辑器是一套界面，同时打开 BMS 和 BMSON。底下仍是两套模型，不能互相套用。人看到的时间线、点选、写入、缩放、滚动、预览是同一套。

同类能力共用前端，后端按来源分模式。例如音频切分：一套切片界面；woslicer 的切点和 BmsONE / bmhelper 的切点各走自己的算法。原版独有的对话框（导入问询、导出 WAV、MIDI 导入）仍按各自来源做，挂在这一套软件里。不要再为 BmsONE、bmhelper、woslicer 各做一扇主程序窗。

还要内置预览，不依赖外置播放器。客户区按原版 Designer 做像素级还原；窗口装饰由系统负责，不另做仿 Windows 边框。未截图不得写像素已通过。
