# uBMplay 参照与现代实现的决策记录

用户明确要求原版只作原始参照，不能照搬过时实现。本记录将外观/谱面合同与内部实现分开，验收不依赖代码相似度。

| 项目 | 需要保留 | 现代实现与验收 |
| --- | --- | --- |
| 外观 | 原始图集的像素、切片、587×256布局、1P/2P与F2切换 | 纹理一次上传、nearest整数缩放、Metal三重缓冲；独立解码原PNG作为像素oracle |
| 时间轴 | BPM/STOP、Here/seek、暂停、播放终点 | 同一音频起点，显示同步采样；谱面秒随RealHS积分，特效使用扣除暂停的墙钟秒 |
| 音频 | 正确音符、采样偏移、长BGM、变速变调与声种开关 | 后台资源准备、提前排程、文件句柄独占交接、长PCM分块；真实输出tap验证音符/频率/间隔 |
| 资源 | 相同随机分支、PATH_WAV含义、未保存编辑 | 预览使用独立快照，不改编辑文档；reload才重选随机分支，旧异步结果按generation丢弃 |
| BGA | 事件优先级、base/layer/poor、黑键、裁切/偏移 | 后台解码与缓存，按事件变化更新图层；坐标用安全宽整数，不复制VB溢出；裁切仍待集成 |
| 空闲 | 停止/暂停/关窗语义 | 不可见时停渲染，保留时间轴结束处理；不用忙等或伪造可见状态 |
| 同采样重叠 | 不漏音，不因提前排程偷掉尚未发声的音符 | 不复制旧单buffer复用的偶然截音；用有界声部池，明确容量和超限处理 |
| RealHS上限 | 操作的含义、步长、中心和变速变调 | 当前UA5仍使用原后端sampleRate/100000Hz上限；待独立审计后按现代后端能力修订，不能把这个限制当格式规范 |

## 2026-10-21 最新决策（覆盖上文旧批次状态）

原版用于界定像素与可观察合同，不作为内部架构模板。BGA裁切已通过静态像素审计，RealHS产品范围25…400；不再保留原100000Hz后端上限。S9/G5/W7与UAT修正后的父代理Release全67/67通过，但产品多node/Varispeed起点缺陷仍未修复。

不采用逐声部任意倍率SRC作为默认后端：32路192k/4x约10–13ms超出256帧5.33ms预算。下一候选将资源后台统一48k立体声，在同一chart sample轴混活动声部，再对总线做一次成熟带限SRC。归一化准备、文件页IO与steady混音/SRC分别测量；SRC预读游标不代表播放位置。候选正在隔离目录验证，尚未接入产品，也不据此宣称帧率或原版对照胜出。

不为代码相似而复制忙等、主线程解码、旧buffer截音、窄整数溢出或采样率硬上限。任何现代替代仍须保留BPM/STOP/Here、尾音、1P/2P/BGA、异步取消及原图集外观；功能缺口不能用“现代化”豁免。


### 频带审计纠正

固定48k资源归一化不获准作为全音质默认：96k源30kHz在0.5倍应成为15kHz，192k源60kHz在0.25倍应成为15kHz，提前48k低通会永久删除它们。依据audit-performance/bus-design-review.md，UAR2R改验有界native-rate分组混音、每组一个SRC并最终合并到唯一输出sample轴；需要直接SRC/错误48k预归一化负对照和慢放频带测试。父代理中断旧UAR2返回130用于传递设计修正，不是测试失败。尚无候选性能通过结论。

UB0另一Grok独占新增PreviewAudio桥目录，准备context-owned stereo SPSC、完整命令快照及安全退休API，暂不连接Legacy/CMake。它与SRC proof互不写入同一文件；通过独立审计后才可交Swift产品owner接入。
