## BUG-01：非零定位后的混音事件延迟

`prepare()` 将音符绝对时间转换成绝对样本位置。`seekAndArm(startMicros)` 计算绝对起点并跳过起点之前的事件，但将 `samplesPlayed_` 重置为零。`fillAudio()` 随后直接把这个相对计数传给 `mixBlock()`，导致未来绝对事件与相对游标比较。

| 定位起点 | 音符绝对时刻 | 期望输出首个非零帧 | 实际首个非零帧 | 结果 |
| --- | --- | --- | --- | --- |
| 0 s | 0.1 s | 4410 | 4410 | 通过 |
| 1 s | 1.1 s | 4410 | 48510 | 延后 1 s |
| 3 s | 3.1 s | 4410 | 136710 | 延后 3 s |

采样率 44100 Hz。探针 PCM 是常量 0.5，避免过零点影响首个非零帧检测。无论声卡是否可用都可重复。

复现命令（仓库根目录）：

```sh
cmake -S out/validation/gui-20261020/seek-probe -B out/validation/gui-20261020/seek-probe/build -G Ninja -DCMAKE_PREFIX_PATH=/opt/homebrew/opt/qt
cmake --build out/validation/gui-20261020/seek-probe/build
out/validation/gui-20261020/seek-probe/build/seek_probe
```

当前退出码为 1。修复后应为 0，三个场景均 PASS。定位代码：`BmsONE/src/player/PlayMixer.cpp` 的 `prepare` / `seekAndArm` / `fillAudio` / `mixBlock`。`GpuPlayerWindow.cpp` 的 READY 和暂停恢复都会调用 `seekAndArm`，因此这些入口需要回归；尚未通过窗口确认它们的可见表现。

## 手动运行与窗口验收

所有测试只使用 `out/validation/gui-20261020/` 下的副本。原始夹具不要覆盖；保存时使用下列新文件名。若应用询问恢复旧自动保存，不恢复旧工作文件。

先运行主编辑器（终端执行）：

```sh
open /tmp/ibms-status-20261020/macos/IBMSNative.app
```

1. File → Open，打开 `out/validation/gui-20261020/input.bms`。应显示标题 `GUI Test Chart`、BPM 120、WAV 01/02 为 `tone.wav`，可见普通音、长音和时值事件。
2. 将 TITLE 改为 `GUI 20261020 保存`，结束文本编辑。标题栏应出现星号。Save As 保存到同目录的 `saved.bms`，星号消失。
3. 撤销、重做；核对保存点的脏标记。重开 `saved.bms`，确认中文标题和音符保留。
4. 选择工具选中一颗普通音，复制到空格，再撤销。切换写入工具在空格写一颗音，再撤销。每步截图并保存副本，以文件内容核对音符；不要仅凭点击坐标推断落点。
5. Edit → Statistics、Find / Delete / Replace，确认能打开并正常关闭。不要预设旧报告的音符数量适用于当前样本和 NT 模式。
6. Preview 菜单从开头播放、停止、再次播放，各重复三轮。通常 F5/F7 对应开始/停止，若系统拦截功能键则用菜单。人工记录是否听见声音；截图无法证明声音。
7. 打开同目录 `input.bmson`：标题 `E2E 中文保存 20260921`、BPM 120、声道 `tone.wav`，一颗 x=1/y=0 短音，一颗 x=2/y=240/l=240 长音。改标题后 Save As 到 `saved.bmson`，重开核对。
8. File → Audio Slicer，打开 `tone.wav`，添加中点裁断，试听前后段，并导出到新建的 `slice-output/`。原音频不得覆盖。记录实际片段数、长度和错误提示。

再运行独立 BmsONE：

```sh
open BmsONE/out/build/macos-arm64-debug/BmsONE.app
```

1. 打开原生写出的 `saved.bmson`，核对声道和两颗音符，窗口应持续响应；再保存为 `qt-saved.bmson`，用原生编辑器重开。
2. 打开 `input.bmson`，Preview → GPU Player from Beginning（F8）。开启自动播放时经过两颗音后 COMBO 应为 2。Stop 后在同窗口 Play，再经过两颗音仍为 2；重复三轮。
3. 打开 `seek-repro.bmson`。该文件每秒有一颗 0.1 秒短音，第一颗在 0.1 秒，之后为 1.1、2.1…9.1 秒。用 Here 从第 3 秒附近开始，记录开始位置、画面过音符和听到声音的相对时刻。
4. 从头播放约 3 秒，Pause，停约 1 秒，再继续；未来音符应按谱面时刻继续，不应额外沉默约 3 秒。暂停期间画面和声音均停止。不要将第 3 步的粗略鼠标起点当作精确探针。
5. 播放中切换缓冲、停止重播、自然结束各复测。截图里的 FPS 仅是应用自报，不能作为显示器真实帧率或音画同步通过的证据。

每项记录：应用路径、输入文件、步骤、期望、实际、是否重复、截图路径。遇到崩溃先保留 macOS 崩溃报告，再停止该用例。Computer Use 获准后可由主代理照此执行；否则用户可直接手动执行。
