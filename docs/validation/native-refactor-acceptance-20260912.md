# 原生编辑器修改与验收记录

这轮已修改编辑、布局、中文和渲染代码，但还不能宣称完整替代原版、达到像素级一致，或解决了所有低帧率场景。编程由 Luna 和 Terra 子代理完成，主代理负责源码复核、构建、测试和界面验收。

## 已完成的主要修改

- 侧栏使用从上到下的坐标布局；BMSON 信息与选中对象区进入统一滚动区域，默认折叠，避免固定高度挤占空间。布局依据本地 VB Designer 源码；尚无同 DPI 的 Windows 运行截图对照。
- 移除 BMP 区错误复制的两个无效复选框。VB 原版的 BMP 区没有这两个控件；原版由 WAV 区的多选开关同时控制 WAV 与 BMP 列表，因此保留这项共用行为。依据 `MainWindow.designer.vb:913-934` 和 `MainWindow.vb:3746-3752`。
- bmhelper 主窗重新安排导入、工程状态、源 MIDI、切分时间线和右侧操作区；修复初始分隔位置。共用切音窗增加可缩放布局、波形区、当前段和上一段预览，以及导出反馈。
- 中文使用独立语言设置和固定文案登记。文件名、谱面字段及用户输入不参加自动翻译。验收中退回过误翻数据、语言切换不能恢复原文，以及测试改动真实用户偏好的实现。
- 新启动建立有效空文档。音符同位置移动仍需验证源音符存在。BMSON 复合编辑失败恢复原文档；BMS 批编辑失败恢复三套快照。
- 长音查询使用区间索引；保留原绘制和命中顺序。同列鼠标移动不再重建 Metal 静态几何。时间选择底色仍位于音符下方。屏外声道跳过波形几何生成。
- 与音频无关的部分选择及额外字段编辑复用主控波形，不再扫描全部混音输入。
- WAV 导出先取得不可变输入快照，再在后台读取、混音和生成文件。关闭或重新载入导出窗口会取消任务，过期回调不会改动新状态。
- WAV 导出排他创建临时文件，完整写入后提交，拒绝覆盖已有目标。测试覆盖已有内容保护、成功 WAV、失败和取消清理，以及两个并发任务争用同名目标。

## 性能证据及限制

同一优化编译基准包含 10 万个普通音符、2 万个长音和 120 个固定视口。测量的是可见长音查询加命中检测：

| 测量 | 中位数 | P95 |
| --- | --- | --- |
| 修改前源码 | 9.1045 ms | 9.3732 ms |
| 修改后源码，子代理复测 | 0.0375 ms | 0.0465 ms |
| 修改后 Release 构建，主代理复测 | 0.0500 ms | 0.0615 ms |

这些数字只证明该 CPU 查询路径减少了开销，不是屏幕帧率。它们不包含完整绘制、文字、音频解码或 GPU 提交。不能换算成稳定 60 FPS。

详细材料位于 `out/audit-20260912/performance/`：`comparison.txt`、`render-performance-audit.md`、`audio-io-audit.md`，以及修改前源码和压力谱面。

## 验收进度

最终统一 Debug 和 Release 构建成功，测试均为 **62/62**。首次测试为 56/59；3 项旧主窗尺寸断言已更新。新增真实常规选项窗口、选中对象视图和 bmhelper 窗口测试，检查语言切换、输入值保护、选中状态变化后的高度通知与控件显隐，以及默认和最小尺寸下的实际窗格边界。核心 AddressSanitizer/UndefinedBehaviorSanitizer 检查为 **17/17**，无现有测试触发的诊断。

最终日志：`out/audit-20260912/acceptance-debug-build.log`、`acceptance-debug-tests.log`、`acceptance-release-build.log`、`acceptance-release-tests.log`。Debug 遇到 Swift 增量编译临时模块路径失效；验收构建改用 `CMAKE_Swift_FLAGS_DEBUG=-Onone -g` 完成重新编译，没有用旧二进制冒充通过。

新版 Release 已通过电脑操作工具打开并查看截图。实测启动即有可编辑标题、BPM 和网格；侧栏分组上下顺序正确；打开已保存的 BMSON 后，信息分组可展开、滚动。选中音符时显示“已选中 1 个音符”，面板自动增加高度并显示长度字段；空态不再溢出。常规选项的中文控件实际显示，未见本次默认尺寸下的主要文字截断。

bmhelper 实测导入 `fixtures/demo.mid` 后生成 5 条 WAV 定义，并成功保存为 `out/audit-20260912/fixtures/gui-roundtrip-20260912.bmh`。第一版主窗未通过布局验收：源 MIDI 区高度仍为 0，右侧按钮分布过散，底部定义区被截断。另确认 WAV 定义窗口的“关闭”按钮没有绑定动作。随后已重新实现窗格尺寸计算，保留可拖动分隔条，固定右侧按钮间距，并绑定关闭动作。最终真实窗口测试通过，覆盖源 MIDI 区、分割区、定义条、列表和 Transpose 按钮边界，也实际执行关闭按钮确认窗口隐藏；最后这版仍待目测复查。

切音窗的中文表单和播放入口已实际显示；上一段按钮文字截断及空音频时仍启用的问题已修复，禁用状态通过真实控制器测试。音频选择过程中 Mac 再次锁屏，工具无法自动解锁，未完成切片导出端到端验证，也未复查最新按钮宽度。不能把算法测试算作此流程的实际操作证据。

旧版实际操作记录见 [初始界面检查](native-ui-audit-20260912.md)。

用户先前未保存的 BMSON 已另存为 `out/audit-20260912/session-preserved-20260912.bmson`，没有覆盖原测试谱面。

## 尚存问题与范围

- 预览的部分音频回退解码仍同步执行；内置预览没有完整下落画面和 BGA 播放器，尚未完成时钟、延迟及高负载同步测试。
- 大谱面的主控波形首次生成、批编辑快照、文字层查询和 Metal buffer 分配仍有进一步优化空间。
- WAV 导出目前依赖目标卷支持硬链接；不支持时会报错，绝不退回覆盖写入。取消在混音后和写入、提交检查点生效，不能立即中断已经开始的 CPU 混音。导出仍会在内存中生成完整 PCM，尚非流式处理。
- 主控制器仍超过 5300 行，职责较集中。此次修复不能代替后续模块拆分。
- BmsONE 独立窗口不是完整编辑器。目前只提供新建、打开、保存、另存、WAV 导出和网格设置；Edit、View、Channel、Help 中其余原版结构菜单均尚未实现，已明确禁用，不能作为可用功能验收。
- woslicer 官方发行包已下载并核对帮助文档，但原生实现仍缺 `.wos` 工程和边缘检测等功能。来源为 [官方站点](https://cerebralmuddystream.nekokan.dyndns.info/)。
- 未逐项运行所有原版菜单、未完成全部格式兼容样本和所有分辨率布局检查。自动测试通过不等于功能完成比例。

事务和区间索引审计详见 [编辑逻辑检查](core-edit-audit-20260912.md)。

最终应用位于 `out/build/acceptance-release/macos/IBMSNative.app`。解锁后应退出之前运行的应用再启动此包，以免继续检查内存中的旧版本。下一步验收：打开保存的 `.bmh`、检查默认及最小尺寸、拖动分隔条、打开音频并完成切片导出，再用压力 BMS/BMSON 测量实际帧时间。

导出复核中还纠正了不允许组合的 Foundation 写入选项，依据 [Apple 的 withoutOverwriting 文档](https://developer.apple.com/documentation/foundation/nsdata/writingoptions/withoutoverwriting)。最终实现未使用该无效组合。
