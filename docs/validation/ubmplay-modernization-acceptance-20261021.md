# uBMplay 现代化收尾验收清单（2026-10-21）

本轮是有界、只读产品的清单审计，只新增本文。依据 S9 / G5 / W7 报告、独立兼容审计及当前状态顶部最新记录；未修改产品、未运行像素基准、未做 UI 自动化或屏幕采集。本文不是新的整体验收通过报告。

当前结论：所测皮肤、静态 BGA、命中生命周期、布局、视频几何及部分媒体时钟已有冻结源证据；**产品音频仍有多 AVAudioPlayerNode 在 Varispeed 下采样起点不一致的问题**。单 Source 与重采样方案仍在隔离验证，尚未接入产品。mine 音源、VOLWAV、特殊模式、最终视频合成像素及可见 presentedTime 均不能写成完成。

## 1. 验收原则

1. 保留用户能观察到的正确谱面、操作、声音、时间和外观合同。现代内部实现可以更换线程、解码、声部、缓存、重采样及显示调度。
2. 原版偶然缺陷和平台限制不作为复刻要求：忙等、主线程解码、单缓冲复用截音、窄整数溢出、DirectSound 的 100000 Hz 上限、旧运行库不可达判档等，不要求照搬。明确的覆盖次序、同分支资源、暂停及 seek 语义不能用“现代化”豁免。
3. 差异不自动等于缺陷。Here 从长音中段进入时，现有策略是声音 carry、长音体可见，不重放 head 判定，也不产生 holding bomb；应明确记录，不能误写成漏音。自动演奏预览不需要因旧判档分支而扩展为人工游玩系统。
4. 最新记录覆盖历史：当前状态顶部与现代化决策的 2026-10-21 追加优先。较早 65/65、66/67、旧音频路径及旧缺陷文字是历史。最新父代理 Release / 67 项 CTest 通过只说明相应冻结构建的回归状态，**不关闭独立真实 PCM 已证实的音频问题**，也不使新后端自动通过。
5. 实现者自测、独立离屏读回、实际图层几何、真实 PCM、窗口呈现分别记证据。原型通过不等于产品通过；文件抽帧不等于最终视频层像素；submit/draw/局部 GPU 时间不等于正 presentedTime。没有同条件原版数据，不作绝对性能结论。

## 3. 明确缺口与未验收项

| 项目 | 当前状态 | 收尾标准及证据限制 |
| --- | --- | --- |
| 产品音频统一时基 | **未完成，已证问题仍在**。当前多 node/Varispeed 起点不一致；固定48k永久归一化已被独立设计审计指出慢放频带回归。UAR2R 当前候选为 native-rate 有界分组混音、每组带限 SRC，最终合并到48k唯一输出轴，仍属隔离验证 | 先完成慢放频带、组间延迟/输出位置、动态切换与预算审计，再接产品。真实输出验证起点、间隔、漏音、频率、动态 rate/pause/seek、输出钟、退休和预算；原型自检不能代替 |
| mine 音源 | **声音未实现**。映射保留 .mine，token 刻意为空，scheduleHits 丢掉空键，不误播地雷数值对应 WAV。原包有 sound/engine.ogg，产品未接 | 提供独立 mine 资源身份及调度；MINE ONLY/全部模式真实可听，其他态不误响；核对触发语义与缺资源状态。不能只把空 token 改成谱面标签。完整包再分发条件不等于可提取单文件发布授权 |
| VOLWAV | **保留数据，未应用增益**。metadata/预览文本保留，音频不消费 | 定义有效值/缺省/非法值及与主音量/headroom 合成次序。原头 Val×0.01 只证明比例入口，不证明最终默认/钳位；以真实 PCM 振幅比签收，不能只看 metadata/菜单 |
| mine 视觉身份 | **完整对应未证明**。PreviewVisualNote 仅 lane/start/end，丢失 mine 类别 | 若要求专用纹素/计数，保留类型并单列审计；正常音符爆炸通过不代表地雷视觉通过，不伪装成人工判定 |
| SkinType4 | **未实现且资源缺失**。scratchRaw 限0…3；原包无 skin_04，二进制有另一组绘制/玩家循环 | 不等同于四种 scratch 的“第4态”。先核用途、资源及权利，明确支持或降级；不伪造图集已还原 |
| PMS/9键、OCT/FP、keyboard/generic/circular 等 | **七键皮肤容量不代表全模式支持**。PLAYER 映射只覆盖5/7/10/14/battle；超槽列可能空矩形，partialDisplay 空串不证明无遗漏 | 分开核对输入模式→模型列→可见列→声音，报告未显示数；明确部分显示或现代适配。不可未知模式默认七键后静默丢键，不凭空制作 skin_04 |
| 最终视频合成像素 | **尚未验收，环境限制**。几何、videoRect、速率、文件抽帧均非最终采样/裁切/谱面Info合成像素 | 用户正常可见且授权允许时再验，记录源SHA/素材/坐标/采集方式。黑帧、AVAssetImageGenerator、CALayer 几何不能代替 |
| 可见 presentedTime | **无有效最终可见结果**。UP2旧pilot正值0且非最终源；锁屏守卫正常抑制提交 | 可见环境冻结最终产品，测正 presentedTime 的p50/p95/p99、长帧比例和CPU/GPU；统一刷新率、像素面积、音符/音频/BGA载荷。draw/submit/FPS标签/准备耗时不能代替 |
| Here 中段长音 | **明确策略边界**：音频carry/体保留，无head判定/holding爆炸 | 当前不列漏音P1；若改持续反馈，单独定义恢复holding、不重播head/不加combo合同 |

| 打包及缺失资源 | **本机读取不等于可发布资源包** | 保留署名/完整包来源，发布方式另行处理；缺皮肤/engine资源明确状态，不独立提交成自有素材，不主动联系作者 |

## 4. 可分配给 Cursor Grok 4.7 High Fast 的小任务

这些是建议批次，尚未派发。不并发写同一文件。音频 owner 工作中时，mine/VOLWAV 先排队，不与后端替换争写 LegacyPreviewAudio.swift。每批冻结SHA、自测、独立定向复验；不减载荷或放松容差换绿。

| 批次 | 独占边界与依赖 | 最小交付与完成条件 |
| --- | --- | --- |
| A：现代音频产品接入 | 沿既有集成合同A/B owner，先完成候选并发、音质/预算、输出钟、缓存与退休门槛；不顺手改W/S/G | 保留现有 ready/cancel/stop/finish/chart/wall/rate API。真实输出签收再完整构建回归，不增第二套UI时间轴 |
| M1：mine | 先小型只读触发/资源合同；实现由音频owner接专用身份，映射owner只改 LegacyBmsonPreview/Tests；构建登记另批 | 可用本地完整包或明确替代策略；不查谱面WAV；声种过滤、Here/seek/pause/cancel正确。真实PCM而非0次调度签收，缺资源可见 |
| M2：VOLWAV | 后端稳定后同一音频owner；复用metadata，必要context增益字段先评审；不改皮肤/BGA | 普通音、BGM、carry、缓存重播一致增益；25/50/100等PCM比例及缺省/非法值。原文不变，不用响度归一化吞掉关系 |
| S：模式容量与mine视觉 | 映射/公共类型合同先冻结，S owner独占Style/View/Tests，桥/构建另批 | 列出模式与实际可见数；明确部分显示；mine类型不丢。SkinType4单独决定支持，不硬塞七键皮肤 |
| G/W：视频最终像素验收 | G提供稳定BGA/素材；W提供整stage/源SHA；正常可见环境再采集 | direct/alias/负源/奇数尺寸、packed/separate、倍率及transport实际像素。环境不能采集就保留未验收，不靠黑图过关 |
| P：最终可见呈现 | 仅探针/输出目录，最终A/S/G/W先稳定；不改守卫或旧before源 | 正presentedTime、有界真实载荷、CPU/GPU分开。无同条件原版数据就只报告本产品，不写绝对更快 |
| C：解析边界 | core随机/长音与预览映射各自独占；一次只选一组缺口 | 先定SWITCH范围，再按最小失败fixture修；资源同源/文档无损。盘符映射不支持应明确平台边界，不生成错误路径 |
| R：最终集成 | 所有实施批次稳定后冻结；构建owner登记全部新源/相关测试链接 | 重新Release和当前完整CTest，不跳过目标；再跑真实PCM/逻辑/媒体定向审计。旧67项通过不沿用到新后端 |

建议先解决产品音频时基；mine/VOLWAV随稳定接口分批接入。模式容量可先做只读清单。视频最终像素与可见presentedTime等待真实可见条件，作为独立批次，不反复重测已关闭像素用例。

## 5. 收尾签收表

- [ ] 新音频后端已接产品，真实输出/统一chart-wall钟、生命周期及预算通过，不仅原型自检。
- [ ] mine专用音源与MINE ONLY/全部模式真实发声，或明确未实现/缺资源；不误播WAV。
- [ ] VOLWAV增益有PCM证据，缺省/非法值及混音策略明确。
- [ ] SkinType4与各模式支持/降级/未显示数明确，没有静默丢列。
- [ ] 最终可见视频合成有证据，或如实保留未验收。
- [ ] 最终正presentedTime与负载/刷新率/源SHA可复现，或如实保留环境阻塞。
- [ ] 最终冻结产品构建和完整回归通过，无未关闭已证P1；测试绿不覆盖独立缺陷。
- [ ] 对外不声称“全逻辑完成”“所有场景像素一致”“绝对超过原版”；现代化/平台/资源边界有记录。
